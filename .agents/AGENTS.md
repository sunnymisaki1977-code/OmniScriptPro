# AI 行為準則：開發前檢查規範

每次使用者提出新增功能、修改邏輯或撰寫新程式碼的請求時，你 **必須** 嚴格遵守以下檢查流程，禁止直接開始寫扣：

1. **強制全域搜尋**：在建立任何新檔案或新功能模組前，你必須先使用 `grep_search` 或 `list_dir` 工具，針對使用者的需求關鍵字，搜尋專案內是否已經有類似名稱的檔案、元件 (Components)、或 API 路由 (Routes)。
2. **優先重用現有功能**：如果你發現專案內已經有做過類似的事情（例如已存在某個 Button 元件、已經有處理過類似邏輯的 Helper 函式），你必須優先修改或引入現有程式碼，**嚴禁**製造重複功能的輪子。
3. **報告檢查結果**：在你的思考或回覆中，請先簡單說明你搜尋了哪些關鍵字、是否找到現有功能，然後才開始撰寫或修改程式碼。
